## 🎯 Problem Statement

> **"Given ball-by-ball data from 200,999 deliveries across 867+ T20 & IPL matches (2022–2026), identify the Top 10 Batters and Top 10 Bowlers who perform best under genuine match pressure — and recommend actionable auction targets for Rajasthan Royals."**

Standard cricket statistics (raw strike rate, economy, average) suffer from two critical blind spots:

- **Context Blindness:** A run scored in a dead-rubber bilateral is treated identically to a run scored during an Over-18 death chase against Jasprit Bumrah in an IPL Qualifier.
- **Historical Anchoring:** A batter's dominant 2022 season is weighted equally with their current 2026 form, masking evolution, decline, or breakout.

The **SupeRR Selector V4 Framework** solves both problems.

## 🚀 Getting Started

### Prerequisites
- Python 3.11+
- Windows 10/11 (tested) or Linux/macOS

### Installation

```bash
# Clone or navigate to the project directory
cd C:\RR

# Create virtual environment
python -m venv .venv

# Activate
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Linux/macOS

# Install dependencies
pip install -r requirements.txt
```

### Run the Pipeline

```bash
python superr_selector_master.py
```

This will:
1. Load all 6 CSV files
2. Reconstruct pre-delivery scoreboard state across 200,999 deliveries
3. Apply the 6-factor contextual multiplier engine
4. Apply exponential recency decay weighting
5. Compute BPI (batting) and BoPI (bowling) composite indices
6. Export all output CSVs and 220 DPI quadrant charts

```bash
streamlit run streamlit_dashboard.py --server.port 8501
```

Then open **http://localhost:8501** in your browser.

```bash
python create_pdf_report.py
```

## 🔬 How Pressure Is Calculated

### The Core Problem

Not every delivery in T20 cricket carries equal weight. A dot ball in Over 3 with the score at 25/0 is fundamentally different from a dot ball in Over 18 with the chasing team needing 42 off 15 balls with 2 wickets in hand. Standard statistics ignore this entirely.

### Pre-Delivery Scoreboard Reconstruction

Before classifying pressure, we first reconstruct the **exact match state** that existed *before* every single delivery across all 200,999 balls in the dataset:

| Metric | Formula | Purpose |
|:---|:---|:---|
| `cum_runs` | Cumulative runs scored by batting team before this ball | Know the current score |
| `cum_wkts` | Cumulative wickets fallen before this ball | Know how many batters remain |
| `balls_bowled` | Count of legal deliveries bowled before this ball | Track match progress |
| `balls_rem` | `max(120 - balls_bowled, 1)` | Remaining resources |
| `target` | 1st-innings total + 1 (2nd innings only) | What the chasing team needs |
| `runs_needed` | `target - cum_runs` (2nd innings only) | How many runs remain to win |
| `RRR` | `(runs_needed / balls_rem) × 6.0` | Required Run Rate per over |

### Binary Pressure Indicator (P_base)

Every delivery is classified as either **pressure (P_base = 1)** or **non-pressure (P_base = 0)** using four objective, scoreboard-derived triggers:

#### Trigger 1: Powerplay & Middle-Over Collapse
```
P_collapse = (overid ≤ 6 AND cum_wkts ≥ 2) OR (overid BETWEEN 7–12 AND cum_wkts ≥ 3)
```
**Why:** Losing 2+ wickets in the powerplay or 3+ by the middle overs creates genuine rebuilding pressure. The batting team must balance survival with run-scoring, and every delivery carries consequence.

#### Trigger 2: 1st-Innings Death Acceleration
```
P_death_inn1 = (innings == 1) AND (overid ≥ 16) AND (cum_wkts ≤ 7)
```
**Why:** Overs 16–20 in the 1st innings are the boundary-maximization phase. Batters must attack aggressively to post a competitive total, and bowlers face extreme pressure to restrict.

#### Trigger 3: 2nd-Innings Death Chase
```
P_death_inn2 = (innings == 2) AND (overid ≥ 16) AND (runs_needed > 0)
              AND (RRR BETWEEN 7.5–22.0) AND (cum_wkts ≤ 8)
```
**Why:** This is the highest-stakes phase in T20 cricket — the final 5 overs of a live chase. The RRR range ensures the match is genuinely competitive (not a walkover or an impossible ask).

#### Trigger 4: Steep Middle-Over Chase
```
P_chase = (innings == 2) AND (runs_needed > 0)
          AND (RRR BETWEEN 9.5–20.0) AND (cum_wkts ≤ 8)
```
**Why:** Chasing teams facing a required rate of 9.5+ RPO even in the middle overs are under sustained pressure to find boundaries while preserving wickets.

#### Garbage-Time Exclusion

Critically, P_base is designed to **exclude stat-padding deliveries**:
- If the match is already decided (RRR > 22.0 with 9 wickets down), that's not real pressure.
- If the chasing team needs 10 runs off 40 balls, that's not real pressure.
- If a batter scores 30*(10) in a dead bilateral match against part-time bowlers, that's not real pressure.

Only deliveries where `P_base = 1` are included in the pressure performance calculations.

### Final Pressure Formula

```
P_base = (P_collapse OR P_death_inn1 OR P_death_inn2 OR P_chase)
```

Each delivery is then multiplied by contextual weight multipliers (see next section) to produce a continuous pressure intensity score rather than a simple binary flag.

## ⚡ The 6-Factor Multiplicative Context Engine

A pressure delivery in an IPL Qualifier against Jasprit Bumrah at Wankhede is objectively harder than a pressure delivery in a bilateral T20I against a part-timer on a flat track. We quantify this using **six orthogonal multipliers**:

### Factor 1: Match Stakes (M_level)

| Context | Multiplier | Rationale |
|:---|:---:|:---|
| IPL Playoffs / Knockouts | **1.30×** | Elimination stakes, winner-takes-all |
| T20 World Cup / Asia Cup Knockouts | **1.22×** | International tournament pressure |
| IPL League Stage | **1.18×** | Highest domestic T20 quality |
| Bilateral T20I Series | **1.05×** | Lower consequence, experimental lineups |

### Factor 2: Venue Pitch Par (M_venue)

Normalizes performance against the venue's historical scoring difficulty:

```
M_venue_bat  = clip(RPO_global / RPO_venue, 0.90, 1.15)
M_venue_bowl = clip(RPO_venue / RPO_global, 0.90, 1.15)
```

Scoring 150 SR on a Chepauk dustbowl (RPO 7.2) is harder than scoring 150 SR at Chinnaswamy (RPO 9.8). This factor levels the playing field.

### Factor 3: Away Hostility (M_away)

| Situation | Multiplier |
|:---|:---:|
| Playing against the home team at their home venue | **1.12×** |
| Home match or neutral venue | **1.00×** |

Performing under hostile crowd conditions with unfamiliar pitch and boundary dimensions is genuinely harder.

### Factor 4: Elite Opposition Matchups (M_opp)

Identifies the **Top 30%** elite players in the dataset:

- **Elite Bowlers:** ≥180 balls bowled AND (economy ≤ 30th percentile OR ≥30 wickets)
- **Elite Batters:** ≥180 balls faced AND (SR ≥ 70th percentile OR ≥600 runs)

| Situation | Multiplier |
|:---|:---:|
| Batter facing an elite bowler | **1.18×** |
| Bowler bowling to an elite batter | **1.18×** |
| Otherwise | **1.00×** |

### Factor 5: Ball Degradation & Dew Physics (M_ball)

Models the physical reality of ball condition changes through an innings:

**For Batters (M_ball_bat):**
| Phase | Multiplier | Physics |
|:---|:---:|:---|
| Overs 1–6 vs Pace | **1.12×** | New ball swings & seams; batter survival is harder |
| Overs 7–15 vs Spin | **1.10×** | Pitch grips in middle overs; spin manipulation peaks |
| Overs 16–20 (Death) | **1.15×** | Yorkers, slower balls, and field spread make boundaries harder |

**For Bowlers (M_ball_bowl):**
| Phase | Multiplier | Physics |
|:---|:---:|:---|
| Overs 1–6 with ≤1 wkt down | **1.10×** | Bowling with new ball but set batters; harder to restrict |
| Overs 16–20, Innings 1 | **1.15×** | Death bowling with established batters attacking |
| Overs 16–20, Innings 2 | **1.20×** | Dew makes ball slippery, grip lost, harder to execute yorkers |

### Factor 6: Innings State (M_inn)

| Situation | Multiplier |
|:---|:---:|
| 2nd Innings with RRR ≥ 10.0 | **1.15×** | Steep chase, every ball decisive |
| 1st Innings with ≥3 wickets down and overid ≤ 12 | **1.12×** | Early collapse recovery under building pressure |
| Otherwise | **1.00×** |

### Combined Context Weight

All six multipliers are combined multiplicatively:

```
W_context_bat  = P_base × M_level × M_venue_bat × M_away_bat × M_opp_bat × M_ball_bat × M_inn
W_context_bowl = P_base × M_level × M_venue_bowl × M_away_bowl × M_opp_bowl × M_ball_bowl × M_inn
```

This means a delivery can have a context weight ranging from **0.00** (non-pressure) through **~1.05** (minimal context) up to **~3.5+** (maximum-stakes delivery in an IPL knockout death over against an elite opponent at a hostile away venue with dew).

## ⏱️ Exponential Recency Decay Model

### Why Recency Matters

Athletes evolve. A player's 2022 performance may reflect a different fitness level, technique, role, or confidence than their 2026 form. Treating all seasons equally creates **historical anchoring bias** — a player who was elite in 2022 but mediocre in 2025–26 still ranks highly on career averages.

### The Decay Curve

Every delivery receives a **year-based recency multiplier** that is applied on top of the context weight:

| Season | M_recency | Relative to 2022 |
|:---:|:---:|:---:|
| **2026** | **1.50×** | 3.33× heavier than 2022 |
| **2025** | **1.25×** | 2.78× heavier than 2022 |
| **2024** | **0.90×** | 2.00× heavier than 2022 |
| **2023** | **0.65×** | 1.44× heavier than 2022 |
| **2022** | **0.45×** | Baseline (lightest) |

### Final Weighted Delivery Score

```
W_bat  = W_context_bat  × M_recency
W_bowl = W_context_bowl × M_recency
```

A death-over delivery in IPL 2026 against an elite bowler at an away venue can carry **5×+ more analytical weight** than a similar delivery in a 2022 bilateral T20I.

### Impact Example

**Ryan Rickelton's Context-Weighted Pressure Strike Rate:**
- At λ = 0.0× (flat, no recency): **177.0 SR**
- At λ = 1.0× (benchmark calibration): **182.4 SR**
- At λ = 2.0× (extreme recency emphasis): **185.9 SR**

His 2025–2026 form is so dominant that increasing recency weight only lifts his rating higher.

## 📊 Performance Indices — BPI & BoPI

All underlying metrics are normalized into standardized **Z-scores** before combining:

$$Z(X) = \frac{X - \mu_X}{\sigma_X}$$

### Batting Pressure Index (BPI)

```
BPI = + 0.25 × Z(Weighted Pressure SR)           → Clutch acceleration ability
      + 0.20 × Z(Weighted Pressure Average)       → Wicket preservation under pressure
      + 0.15 × Z(2025–26 Pressure SR)             → Recent 24-month clutch form
      + 0.15 × Z(Weighted Boundary %)             → Boundary-hitting under defensive fields
      − 0.10 × Z(Weighted Dot Ball %)             → Penalty for scoreboard stagnation
      + 0.10 × Z(Δ SR Lift)                       → Elevation above career baseline
      + 0.05 × Z(Avg Pressure Intensity)          → Exposure to high-stakes contexts
```

**Key Insight:** The formula rewards players who **elevate their game under pressure** (positive SR Lift), not just players who have a high raw strike rate. A player who scores at 180 SR all the time but drops to 170 under pressure is penalized relative to a player who scores 150 normally but rises to 170 under pressure.

### Bowling Pressure Index (BoPI)

```
BoPI = − 0.25 × Z(Weighted Pressure Economy)      → Run restriction when it matters
       − 0.20 × Z(Weighted Pressure Strike Rate)   → Wicket-taking frequency under pressure
       − 0.15 × Z(2025–26 Pressure Economy)        → Recent restriction form
       + 0.15 × Z(Weighted Dot Ball %)             → Chokehold creation ability
       − 0.10 × Z(Weighted Boundary %)             → Boundary prevention
       − 0.10 × Z(Δ Economy Drop)                  → Tightening relative to baseline
       + 0.05 × Z(Avg Pressure Intensity)          → High-stakes death bowling exposure
```

**Note:** Negative signs on economy and SR mean **lower is better** for bowlers — a bowler who concedes fewer runs and takes wickets more frequently under pressure scores higher.

## 🔀 List A vs List B — Why List A Is a Benchmark, Not the Answer

This is one of the most important architectural decisions in the framework:

### List A: "The Full Picture" (Unrestricted IPL 2026 Benchmark)

**What it includes:** Every active player in the IPL 2026 season, including retained franchise core players like Jasprit Bumrah, Virat Kohli, Suryakumar Yadav, Sanju Samson, etc.

**Sample size gates:** ≥25 matches, ≥150 career pressure balls, ≥60 recent (2025–26) pressure balls.

**Purpose:** Validates that our pressure model **makes cricketing sense**. If the Top 5 of List A includes names like Bumrah, Suryakumar, and Kohli, we know the framework is correctly identifying elite performers.

**Why it's NOT the submission:** List A includes players like Jasprit Bumrah (retained by MI for ₹18 Cr), Virat Kohli (retained by RCB), and Sanju Samson (retained by RR). These players are **untouchable franchise assets** — they will never appear in the IPL auction. Recommending "buy Bumrah" to Rajasthan Royals is useless advice because Bumrah is not available.

**Total:** 83 batters, 77 bowlers.

### List B: "The Actionable Answer" (IPL 2027 Auction Targets)

**What it excludes on top of List A filters:**

1. **67 Untouchable Franchise Cores** — Retained stars who will never be released:
   - RR: Yashasvi Jaiswal, Sanju Samson, Riyan Parag, Shimron Hetmyer, Dhruv Jurel, Jofra Archer...
   - MI: Jasprit Bumrah, Suryakumar Yadav, Hardik Pandya, Rohit Sharma, Tilak Varma...
   - CSK: Ruturaj Gaikwad, MS Dhoni, Matheesha Pathirana, Ravindra Jadeja...
   - RCB: Virat Kohli, Rajat Patidar, Yash Dayal, Cameron Green...
   - And 40+ more across all 10 franchises.

2. **All Pakistan Players** — Programmatically identified via `team_name == 'pakistan'` in `competition_team_player_mapping.csv`. Pakistani players cannot participate in the IPL due to geopolitical restrictions.

3. **24 Retired/Inactive Players** — Dinesh Karthik, Shikhar Dhawan, AB de Villiers, Chris Gayle, David Warner, etc.

**Sample size gates:** ≥80 career pressure balls, ≥40 recent (2025–26) pressure balls.

**Purpose:** Every player in List B is someone Rajasthan Royals can **actually bid for** in the next IPL mega-auction. This is the list submitted to the Unstop dropdown.

**Total:** 57 batters, 80 bowlers.

### Why This Separation Matters

> Without this separation, any pressure model would inevitably rank Bumrah #1 among bowlers and Suryakumar Yadav in the top 3 among batters. While that validates the model, it provides **zero actionable intelligence** to an auction strategist. List B answers the real question: *"Among players we can actually buy, who performs best under pressure?"*

## 🔍 Reliability & Limitations

### Sensitivity Analysis

| Test | Result |
|:---|:---|
| **Threshold Sweep (60–120 min pressure balls)** | Top 5 ranking order (Nair, Rickelton, de Kock, Sharma, Nissanka) is strictly stable. Rank correlation > 0.94 across all thresholds. |
| **Recency Sweep (λ = 0.0× to 2.0×)** | Karun Nair and Ryan Rickelton remain #1 and #2 across all settings — both career-consistent AND recent-form dominant. |
| **Weight Perturbation (±5% on all Z-score components)** | Top 10 membership is stable; only minor reordering within ranks 6–10. |

### Known Limitations

1. **No Dropped Catch Data:** The dataset lacks fielding telemetry. A bowler who beats the edge 5 times but gets dropped twice appears identical to one who bowls 5 dot balls.
2. **No Ball-Tracking Physics:** Seam movement (mm), spin rate (RPM), and release point data are unavailable. Future iterations could isolate bowler execution quality from pitch assistance.
3. **Venue Sample Size:** Some venues have very few matches, making their RPO estimates less reliable. The clip(0.90, 1.15) range mitigates extreme outliers.
4. **Binary Pressure vs Continuous:** While context weights create a continuous spectrum, the base P_base trigger is still binary. Future work could model a fully continuous pressure surface.
